# HopperSpeed Global v1.0.0

**Primeira versão pública — Minecraft Java 1.21.8 / Forge 58.1.26**

Esta versão permite aumentar a velocidade de transferência de **todos os funis vanilla em chunks carregados**, sem acelerar o jogo inteiro.

### Como usar

```mcfunction
/hopperspeed 1
```

Esse comando configura o intervalo de transferência em 1 tick (até 8× o padrão). Para restaurar:

```mcfunction
/hopperspeed reset
```

### Instalação

1. Instale Forge 58.1.26 para Minecraft Java 1.21.8.
2. Coloque o arquivo `hopperspeed-forge-1.21.8-1.0.0.jar` na pasta `mods` da instalação Forge, quando o mantenedor o disponibilizar nesta Release.
3. Execute o jogo e use o comando com permissão de nível 2.

**Observações:** faça backup do mundo; não acelera funis de chunks descarregados; a taxa real depende da farm. Mais detalhes no README.
